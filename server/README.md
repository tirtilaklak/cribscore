# Research analysis helpers

These ES modules are pure, offline helpers in the source repository. The static site serves only `dist/`; no server helper, raw source capture, private audit, or synthetic fixture is part of its deployment archive.

The path from an authorized price response to a research display is: exact-byte transport capture → independently accepted host-ingestion record → observed-evidence bridge → corporate-action-aware price calculation → separate component and rights review → research scorer → separately reviewed public-case and metadata projection. The browser has a dormant approved-byte reader boundary, with no reader or endpoint configured.

The modules do not turn JSON assertions into authentication or actual approvals. An owner-authenticated controller, current provider entitlement and publication rights, complete reviewed calendar/security/action coverage, actual source freshness, complete financial context, separately reviewed component records and exact output approval remain necessary. No collector, scheduler, durable storage, new credential, paid data request or publisher is activated here.

The research evidence score is an unvalidated equal-weight four-component rubric. It is not an expected return or gain probability. Up to ten eligible reviewed cases may be shown; missing cases never get backfilled to reach five. Equal scores share competition rank, and full-assessment tie status survives display projection.

Run `npm test` at the project root for app and helper contract checks. All market/score/slate fixtures are synthetic. Retained company cases remain unranked with price, expected return and probability unavailable.
