# Captured-pair orchestration

`evaluateCapturedPair(previousReceiptLedger, event)` joins the real transport envelope, independently accepted host-ingestion record, reviewed target and benchmark records, generic ingestion and corporate-action-aware historical calculator. It never fetches, persists, schedules, grants a candidate gate or authorizes delivery. `emptyReceiptLedger()`, `fingerprintTransportEnvelope()` and `serializePriceActionReview()` are the other exported helpers.

The event supplies run/revision IDs, actual operation time and source cutoff, a reviewed calendar, target/benchmark inputs, the explicit declared convention and `toleranceBps:0`. Each leg supplies transport, ingestion record, authorization, policy, rights reviews, identity/basis/action reviews and the latest complete host-check record. An ETF is supported only as an explicitly reviewed benchmark; the target remains common equity.

The host-assigned accepted ingestion record must bind actual response hash/length, request/completion/ingestion clocks and the separate deterministic `transportEnvelopeSha256` seal. This normalized-envelope seal is not the raw-response-byte hash; original response bytes are not reverified here. Trusted complete host records and source registries remain necessary. Matching arbitrary JSON is not proof of origin, rights, authentication or an omitted later failure.

The historical convention is `five-session-close-cash-entitlements-v1`, grade rule `absolute-and-relative-sign-neutrality-v2`, numerical neutrality `return-units-neutral-band-1e-12-v1`, sign policy `research-score-price-action-zero-neutrality-v1`, with exactly zero economic tolerance. See `../research-score/policy.md` for the roundoff boundary. Both legs must succeed together; current rights and freshness are rechecked. A failed pair never borrows an earlier grade.

Frozen hash-chained receipts form a returned memory-only ledger with revision/run conflict checks. Identical replay returns a historical receipt, never cached numeric/display output. A malformed ledger returns an unrecorded error, and callers must not replace real history with it. These checks detect inconsistent supplied records; they do not authenticate a host or prevent replacement/rollback. Durable atomic storage is not implemented.

Numerical returns, action cash and terminal holdings remain in the non-enumerable private result. The allowlisted review serializer omits numeric returns, raw prices/volumes, source hashes and receipt lineage. Its coarse grade is a review draft; derived-display denial suppresses it. All candidate, score, ranking and delivery flags remain false, and expected return/probability stay null.

A separate trusted reviewer must bind the calculation ID, conventions, both distinct snapshot IDs and provider/source lineages, benchmark, exact measurement endpoints, both actual capture/ingestion clocks and actual calculation time into the price component. Calculation must follow both ingestions and precede review/cutoff. No review clock may be backdated to make an older cutoff fit. Other components, all candidate gates, current rights and exact approved output remain independently required. No current real stock has such approval.
